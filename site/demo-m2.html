М2. Вынужденные колебания: сила Q₀·sin ωt

К той же системе (М1) приложим гармоническую силу: q̈ + 2μq̇ + λ²q = (Q₀/M)·sin ωt. Сначала виден переходный процесс (затухающие собственные колебания), затем остаются чистые установившиеся колебания с частотой силы и амплитудой α·Q₀/C. Коэффициент динамичности α — главная кривая всей вибрации: подведите ω к λ и посмотрите на резонанс.

Вынужденные колебания и α

Красная стрелка — сила Q(t) = Q₀·sin ωt.
полное решение q(t) ±α·Q₀/C (установившийся размах)
Резонансная кривая α(ω/λ); точка — текущая настройка. Кривая перестраивается при изменении μ.

Решение по шагам

Серым — подстановка текущих значений, жирным — результат.

Что смотреть. Пик кривой — чуть левее ω/λ = 1 (точный максимум при ω = λ√(1−2μ²/λ²)); высота пика ≈ λ/2μ. При ω ≪ λ груз движется «как статика» (α → 1), при ω ≫ λ — не успевает за силой (α → 0, противофаза). Увеличьте μ — пик оседает: так работает демпфирование судовых конструкций.
Примечание. Исходный Mathcad-файл этой модели (mass_on_spring_force) остался недописанным — здесь приведено полное решение по теме 4 конспекта: установившаяся часть α·(Q₀/C)·sin(ωt−ε) плюс переходный процесс из нулевых начальных условий.

Самопроверка при дефолтах (M=10, C=1000, μ=1, ω=5): α = 1,321635; амплитуда установившихся 0,132164 м — формулы темы 4 конспекта.
