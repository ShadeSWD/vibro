М4. Линейка на вибростенде

Классический лабораторный опыт: пластиковую линейку (\(E = 2\) ГПа, \(\rho = 2350\) кг/м³, сечение 25×1 мм, вылет \(L = 260\) мм) зажимают в головке вибростенда, которая ходит вверх-вниз с амплитудой \(f = 10\) мм и частотой ν. Балка отвечает формой \(w(x,t) = w_1(x)\sin\omega t\), где \(w_1(x)\) — решение уравнения \(EI\,w'''' = m\omega^2 w\) с условиями заделки и свободного конца. Крутите частоту через резонанс — форма перестраивается, появляется узел.

Колебания балок Вынужденные колебания балок

линейка w(x,t) огибающая ±w₁(x) узел формы (точка не движется)

Решение по шагам

Серым — подстановка текущих значений, жирным — результат. При дефолте (ν = 15 Гц) константы совпадают с контрольным примером.

Что смотреть. Ниже первого резонанса (\(\nu < \lambda_1 = 2{,}2\) Гц) линейка ходит почти как жёсткая. Между λ₁ и λ₂ конец машет сильнее заделки. При переходе через \(\lambda_2 = 13{,}8\) Гц форма «переламывается»: возникает узел — точка, которая стоит на месте, хотя заделка и конец колеблются. На шкале частот резонансы отмечены красным; попадёте в них — амплитуда (в модели без трения) неограниченно растёт.

Контрольный пример, \(\nu = 15\) Гц: \(\mu = 4{,}891180\); \(A = 0{,}00409696\); \(B = -0{,}00598006\); \(C = 0{,}00401994\); \(D = -0{,}00409696\); \(\lambda_1 = 2{,}207\) Гц; \(\lambda_2 = 13{,}819\) Гц.
