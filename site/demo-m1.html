М1. Свободные затухающие колебания

Груз массой M висит на пружине жёсткостью C; движению мешает вязкое сопротивление (коэффициент затухания μ). Оттянем груз на q₀ и толкнём со скоростью v₀ — дальше система живёт сама: \(\ddot{q} + 2\mu\dot{q} + \lambda^2 q = 0\), где \(\lambda = \sqrt{C/M}\) — собственная частота. Всё на этой странице пересчитывается ползунками на лету.

Решение по шагам

Серым — подстановка текущих значений ползунков, жирным — результат. При значениях по умолчанию \((M = 10,\ C = 1000,\ \mu = 1,\ q_0 = 0{,}1,\ v_0 = 1)\) числа совпадают с расчётом кафедры.

Что смотреть. Амплитуда гаснет по экспоненте — соседние размахи относятся как \(e^{\mu T}\) (логарифмический декремент \(\delta = \mu T\)). Затухание почти не меняет частоту: при \(\mu = 1\) и \(\lambda = 10\) частота падает всего до \(\lambda' = 9{,}95\). Сделайте \(\mu^2 > \lambda^2\) — колебания исчезают вовсе: система апериодически сползает к равновесию (кнопка «Апериодика»).

Сверено с расчётом кафедры: \(\lambda = 10\); \(\lambda' = 9{,}94987\); \(A = 0{,}149071\); \(\varepsilon = 0{,}835482\).
