Глава 2. Система с одной степенью свободы

Груз на пружине — простейшая модель, на которой видна вся механика вибрации: собственная частота, затухание, резонанс. Всё, что выведено здесь, дальше дословно повторится для балок, пластин и корпуса — изменится лишь смысл «массы» и «жёсткости».

Оглавление Модель М1: свободные колебания Модель М2: резонанс

2.1. Вывод уравнения движения

Груз массой M висит на пружине жёсткости C (сила пружины пропорциональна её деформации: \(F_{\text{упр}} = C\Delta\)). Отсчитываем координату q от положения статического равновесия — тогда сила тяжести и статическая деформация пружины взаимно уничтожаются и в уравнение не входят. При отклонении q на груз действуют:

  • восстанавливающая сила пружины \(-Cq\) (к равновесию);
  • сила сопротивления, принимаемая вязкой: \(-R\dot q\) (против скорости);
  • внешняя возмущающая сила \(Q(t)\).
Расчётная схема: масса, пружина C, демпфер R, сила Q(t); координата q — от положения равновесия.

Второй закон Ньютона (или принцип Даламбера, добавляющий силу инерции \(-M\ddot q\) к условию равновесия):

$$M\ddot q = -Cq - R\dot q + Q(t).$$

Делим на M и вводим стандартные обозначения \(2\mu = R/M\), \(\lambda^2 = C/M\):

$$\ddot q + 2\mu\dot q + \lambda^2 q = \frac{Q(t)}{M}, \qquad \lambda = \sqrt{\frac{C}{M}}.$$

Это основное уравнение теории вибрации: λ — собственная частота (рад/с), μ — коэффициент затухания (1/с). Дальше разбираем его по частям: сначала свободные колебания \((Q = 0)\), затем вынужденные.

2.2. Свободные колебания без сопротивления

При \(\mu = 0,\ Q = 0\): \(\ddot q + \lambda^2 q = 0\). Общее решение —

$$q = C_1\cos\lambda t + C_2\sin\lambda t = A\cos(\lambda t - \varepsilon).$$

Постоянные находим из начальных условий \(q(0) = q_0\), \(\dot q(0) = v_0\): подстановка даёт \(C_1 = q_0\), \(C_2 = v_0/\lambda\), откуда амплитуда и начальная фаза

$$A = \sqrt{q_0^2 + \frac{v_0^2}{\lambda^2}}, \qquad \operatorname{tg}\varepsilon = \frac{v_0}{\lambda q_0}.$$

Движение — гармоника с периодом \(T = 2\pi/\lambda\). Частота не зависит от начальных условий — это свойство линейной системы: как ни толкни, период один и тот же. Полная энергия \(\tfrac12 M\dot q^2 + \tfrac12 Cq^2 = \tfrac12 CA^2\) сохраняется, перекачиваясь из кинетической в потенциальную дважды за период. Живая модель М1

2.3. Затухающие колебания. Декремент

С сопротивлением \((\mu > 0,\ Q = 0)\) ищем решение в виде \(q = e^{kt}\); подстановка даёт характеристическое уравнение

$$k^2 + 2\mu k + \lambda^2 = 0, \qquad k_{1,2} = -\mu \pm \sqrt{\mu^2 - \lambda^2}.$$

Случай слабого сопротивления \(\mu^2 < \lambda^2\) (все судовые конструкции). Корни комплексные: \(k_{1,2} = -\mu \pm i\lambda'\), где

$$q(t) = A\,e^{-\mu t}\cos(\lambda' t - \varepsilon), \qquad \lambda' = \sqrt{\lambda^2 - \mu^2}.$$

Начальные условия \(q_0,\ v_0\) дают \(A = \sqrt{q_0^2 + \bigl((v_0 + \mu q_0)/\lambda'\bigr)^2}\), \(\operatorname{tg}\varepsilon = (v_0 + \mu q_0)/(\lambda' q_0)\). Колебания происходят с чуть уменьшенной частотой λ′ внутри экспоненциальной огибающей \(\pm Ae^{-\mu t}\). Отношение двух последовательных амплитуд одного знака (через условный период \(T' = 2\pi/\lambda'\)) постоянно:

$$\frac{a_i}{a_{i+1}} = e^{\mu T'} = \text{const}, \qquad \delta = \ln\frac{a_i}{a_{i+1}} = \mu T'$$

— амплитуды убывают в геометрической прогрессии, а δ называется логарифмическим декрементом колебаний. Его удобно мерить по осциллограмме — и по нему восстанавливать μ. Важно: затухание, заметно съедая амплитуду, почти не меняет частоту:

Поэтому при расчёте собственных частот судовых конструкций затуханием пренебрегают \((\lambda' \approx \lambda)\), а при расчёте резонансных амплитуд — нет.

Случай сильного сопротивления \(\mu^2 > \lambda^2\). Оба корня вещественны и отрицательны:

$$q = e^{-\mu t}\left(C_1 e^{\sqrt{\mu^2-\lambda^2}\,t} + C_2 e^{-\sqrt{\mu^2-\lambda^2}\,t}\right)$$

— движение апериодическое: выведенная из равновесия система сползает к нему, ни разу его не перейдя (максимум один переход при большой начальной скорости). Граница \(\mu = \lambda\) — критическое затухание, самый быстрый возврат к равновесию (так настраивают демпферы измерительных приборов).

Затухающие колебания (μ < λ) в огибающей ±Ae−μt и апериодическое движение (μ > λ) при тех же начальных условиях.

2.4. Произвольная сила: интеграл Дюамеля

Реакцию на любую силу Q(t) можно собрать из откликов на элементарные импульсы \(Q(\tau)d\tau\): каждый импульс сообщает массе скорость \(Q(\tau)d\tau/M\), после чего система свободно затухает. Суммирование по всем импульсам даёт интеграл Дюамеля:

$$q(t) = \frac{1}{M\lambda'}\int_0^t Q(\tau)\, e^{-\mu(t-\tau)}\sin\lambda'(t-\tau)\,d\tau .$$

Им решают задачи об ударных нагрузках (слеминг, подрыв). Для главного судового случая — периодической силы — удобнее прямой путь, к нему и переходим.

2.5. Вынужденные колебания. Вывод коэффициента динамичности

Пусть \(Q = Q_0\sin\omega t\). Общее решение = свободные затухающие колебания (переходный процесс, исчезает за несколько периодов) + частное решение — установившиеся вынужденные колебания. Ищем частное решение с частотой силы:

$$q_\text{в} = B_1\sin\omega t + B_2\cos\omega t.$$

Подставляем в \(\ddot q + 2\mu\dot q + \lambda^2 q = (Q_0/M)\sin\omega t\). Производные: \(\dot q_\text{в} = \omega(B_1\cos\omega t - B_2\sin\omega t)\), \(\ddot q_\text{в} = -\omega^2 q_\text{в}\). Собирая коэффициенты при \(\sin\omega t\) и \(\cos\omega t\) (равенство должно выполняться в любой момент, значит по каждой из двух функций отдельно):

$$\begin{aligned} (\lambda^2 - \omega^2)B_1 - 2\mu\omega B_2 &= \frac{Q_0}{M},\\ 2\mu\omega B_1 + (\lambda^2 - \omega^2)B_2 &= 0. \end{aligned}$$

Решение системы (определитель \(D = (\lambda^2 - \omega^2)^2 + 4\mu^2\omega^2\)):

$$B_1 = \frac{Q_0}{M}\cdot\frac{\lambda^2 - \omega^2}{D}, \qquad B_2 = -\frac{Q_0}{M}\cdot\frac{2\mu\omega}{D}.$$

Переходим к амплитудной форме \(q_\text{в} = a\sin(\omega t - \varepsilon)\):

$$a = \sqrt{B_1^2 + B_2^2} = \frac{Q_0}{M\sqrt{D}}, \qquad \operatorname{tg}\varepsilon = -\frac{B_2}{B_1} = \frac{2\mu\omega}{\lambda^2 - \omega^2}.$$

Амплитуду принято сравнивать со статическим прогибом — смещением под той же силой, приложенной медленно: \(q_{\text{ст}} = Q_0/C = Q_0/(M\lambda^2)\). Их отношение — коэффициент динамичности:

$$\alpha = \frac{a}{q_{\text{ст}}} = \frac{\lambda^2}{\sqrt{D}} = \frac{1}{\sqrt{\left(1 - \dfrac{\omega^2}{\lambda^2}\right)^{\!2} + \dfrac{4\mu^2\omega^2}{\lambda^4}}}.$$

Свойства α как функции расстройки \(z = \omega/\lambda\):

  • \(\omega \ll \lambda\): \(\alpha \to 1\) — сила действует квазистатически;
  • \(\omega \gg \lambda\): \(\alpha \to 0\) — масса «не успевает» за силой, колебания исчезают;
  • максимум при \(\omega = \lambda\sqrt{1 - 2\mu^2/\lambda^2} \approx \lambda\) — резонанс; высота пика \(\alpha_{\max} \approx \dfrac{\lambda}{2\mu} = \dfrac{\pi}{\delta}\) ограничена только затуханием: при декременте δ = 0,1 усиление в ~30 раз;
  • фаза: ниже резонанса движение в фазе с силой \((\varepsilon \approx 0)\), в резонансе отстаёт ровно на \(\pi/2\) (сила «в такт скорости» — идеальная накачка энергии), выше — в противофазе \((\varepsilon \to \pi)\).
Резонансные кривые α(ω/λ) при разных уровнях затухания μ/λ.

Практический вывод для судна: единственные надёжные способы снизить вынужденную вибрацию — отстройка от резонанса (изменить λ жёсткостью или массой, изменить ω оборотами) и уменьшение самой силы \(Q_0\) (балансировка, число лопастей); увеличение затухания работает только вблизи резонанса.
