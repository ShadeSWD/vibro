Источники

Сайт собран по материалам семестрового курса и расчётным файлам кафедры; для углубления — классические учебники.

Основа сайта

  1. Конспект лекций по курсу «Вибрация корабля». СПбГМТУ, 2023. Рукопись.
    Темы 1–13: возмущающие силы, системы с одной и многими степенями свободы, балки, рамы, пластины, метод Релея, общая вибрация корпуса.
  2. Mathcad-модели кафедры (учебные расчётные файлы):
    mass_on_spring — свободные затухающие колебания (М1); mass_on_spring_force — вынужденные колебания, файл не завершён, решение на сайте доведено по теме 4 конспекта (М2); two_mass_on_spring — цепочка из двух масс (М3); console_beam — консольная балка на вибростенде (М4); automobile, automobile_on_the_road — автомобиль на неровной дороге, интегрирование Рунге–Кутты (М5).
