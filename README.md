# vibro — Вибрация корабля: живой учебный курс

Статический сайт по курсу СПбГМТУ «Вибрация корабля»: конспект теории плюс
пять параметрических анимаций — от массы на пружине до автомобиля на неровной
дороге и изгибных форм корпуса судна. Никаких библиотек и серверных расчётов:
чистый SVG + ванильный JavaScript, аналитика решается в браузере,
интегрирование — Рунге–Куттой прямо в кадре анимации.

**Прод:** https://shadeswd.duckdns.org/vibro/ (отдаётся через nginx кластера)

## Содержание
- `site/` — сам сайт (без сборки, чистые HTML/CSS/JS)
  - `index.html` — витрина курса с мини-анимацией затухающих колебаний
  - `models.html` — оглавление пяти живых моделей
  - `demo-m1…demo-m5.html` — пять параметрических анимаций:
    М1 масса на пружине (свободные затухающие колебания), М2 вынужденные
    колебания и резонанс, М3 две массы (формы и биения), М4 линейка на
    вибростенде (консольная балка), М5 автомобиль на неровной дороге
    (2 степени свободы, Рунге–Кутта)
  - `theory.html` — оглавление конспекта; страницы глав `t-sources.html`,
    `t-single.html`, `t-two.html`, `t-beams.html`, `t-plates.html`,
    `t-energy.html`
  - `problems.html` — 14 задач с разбором по шагам (качка и груз на кране,
    виброизоляция фундамента, динамический гаситель, настил и ребро жёсткости,
    двухузловая частота корпуса и формула Кумаи, отстройка от лопастной частоты,
    декремент по осциллограмме, критическая частота вала, биения, слеминг,
    мачта, плескание в цистерне, влияние закрепления балки, нормы обитаемости)
  - `norms.html` — нормирование вибрации: ISO 6954:2000 (зоны A/B/C),
    кривая частотной коррекции ISO 2631-2, серия ISO 20283, критерии SSC-350,
    ISO 20816/10816 для механизмов, СП 2.5.3650-20, нотации комфорта
    классификационных обществ, методика замеров и меры при превышении
  - `hull.html` — общая вибрация корпуса судна (свободная балка переменного
    сечения, присоединённая вода, лопастная частота)
  - `sources.html` — источники: конспект СПбГМТУ 2023, Mathcad-модели кафедры,
    классика (Постнов, Тимошенко, Ден-Гартог, PNA, SSC-350) и стандарты —
    с указанием, что именно откуда взято
  - `assets/` — `style.css`, `site.js` (общая навигация), `vibro.js` (движок
    SVG-анимаций: `V.el`, `V.loop`, пружины, засечки)
- `deploy/` — docker-compose (nginx:alpine, 127.0.0.1:8071) + конфиг nginx

## Запуск локально
```bash
cd deploy && docker compose up -d   # проект называется vibro (name: обязателен!)
```
Сайт поднимется на 127.0.0.1:8071. Наружу отдаётся через nginx хоста
(location /vibro/). Clean-URL: nginx `try_files $uri $uri.html $uri/` —
ссылки идут без расширения `.html`.

## Тесты
```bash
python3 -m pytest tests/ -q
```
Дополнительно каждая страница с расчётами содержит самопроверку: числовые ответы
пересчитываются в браузере из исходных данных и сверяются с напечатанными
(`V.selfcheck`, результат — в консоли, ключи `problems`, `norms`, `t-single`,
`t-two`, `t-beams`, `t-plates`, `m1`…`m5`).

`tests/test_site.py` параметризованно проверяет каждую HTML-страницу (корректный
разбор, отсутствие дублей id, целостность локальных ссылок/ассетов с учётом
clean-URL nginx) и синтаксис каждого JS (`node --check`). Тот же прогон
выполняет GitLab CI (`.gitlab-ci.yml`).
